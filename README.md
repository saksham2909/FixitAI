# FixitAI

FixitAI is a human-aligned, evidence-based Resume–Job Description (JD) compatibility framework built as a demonstration system for a research review paper. It parses resumes (PDF/DOCX) and JD text through a seven-step pipeline — requirement extraction, semantic matching, evidence attribution, weighted scoring, and natural-language explanation — and benchmarks the results against five established baselines (keyword overlap, TF-IDF, embedding similarity, direct LLM scoring, and the FixitAI system itself) using information-retrieval metrics (Precision@K, nDCG, MRR, F1) validated against human rater judgements via Spearman and Pearson correlation. A Streamlit interface provides an interactive demo, and optional fairness probes (name/gender swap) are included to audit bias in the pipeline.
