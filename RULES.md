# FixitAI — Project Rules

These rules apply to every task in this repository. Follow them without exception.

## Rule 1 — Think Before Coding
State your assumptions explicitly before writing any code.  
If a requirement is ambiguous or has multiple valid interpretations, ask the user — never pick silently between interpretations.

## Rule 2 — Simplicity First
Implement only what was asked. No extra features, no pre-emptive abstractions, no "while I'm at it" additions.

## Rule 3 — Surgical Changes
Touch only the files and lines required for the task.  
Do not refactor, rename, or reorganise code that is unrelated to the current change.

## Rule 4 — Goal-Driven
For every task, state a verifiable success check (a specific test command or run command) before starting.  
Run it and confirm it passes before declaring the task done.
